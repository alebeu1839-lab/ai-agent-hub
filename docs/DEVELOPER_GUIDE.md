# AI Agent Hub — モック実行ガイド

**現段階は開発用コードです。実際のGPT / Claude Code / Codexとは未接続です。**

## 動作確認

Python 3.10以降でリポジトリのルートから:

```sh
python -m unittest discover -s tests -v
```

## 構成

- `hub/task_store.py`: SQLite保存、状態遷移、履歴、重複登録の防止
- `hub/dispatcher.py`: 登録済み内部ワーカーの実行、検品待ち、失敗記録
- `hub/retry_planner.py`: 利用制限後の再試行時刻を永続保存、期限到達後キュー復帰
- `hub/queue_runner.py`: 部署ごとの内部ワーカー振り分け、1回の実行件数制限

## 安全上の制限

- 実際のメール、応募、契約、納品、公開、支払などの外部操作は**すべて無効**。認証済み承認台帳と専用コネクタの実装までは許可しない
- `retry_planner.requeue_due()` は仕事をキューに戻すだけ。勝手に外部送信しない
- キュー処理は呼び出し側が `tick()` を実行した時のみ。常時稼働するスケジューラは未実装
- 連続稼働・複数プロセス排他・リース期限・予算管理・署名付き承認・AIプロバイダ接続は未実装
- 開発中のテストに成功しても本番使用可を意味しない
